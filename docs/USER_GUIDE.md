## Getting Started

### Creating Your Account

1. Visit [alphaforge.com](https://alphaforge.com) and click "Sign Up"
2. Enter your email and create a secure password
3. Verify your email address via confirmation link
4. Complete your profile with basic information
5. Enable two-factor authentication (recommended)

### Initial Setup

1. **KYC Verification**: Complete Know-Your-Customer verification
   - Provide government-issued ID
   - Verify address
   - Confirm investment experience

2. **Exchange Connection** (Optional)
   - Connect Binance, OKX, or Bybit accounts
   - Enable restricted API keys for security
   - Set position size limits

3. **Risk Configuration**
   - Set daily loss limits
   - Configure maximum position size
   - Choose risk level (Conservative/Moderate/Aggressive)

## Beginner Guide

### Understanding Trading Signals

**What is a Signal?**
- An automated recommendation to BUY or SELL
- Generated by AI analyzing multiple data sources
- Includes confidence score (0-100%)
- Shows risk/reward ratio

**How to Read a Signal**
```
BTC/USD - BUY Signal
├─ Confidence: 82%
├─ Entry Price: $52,000
├─ Target: $54,000 (+3.8%)
├─ Stop Loss: $50,000
└─ Risk/Reward: 1:1.9
```

### Viewing Signals

1. Go to **Dashboard** → **Top Trading Signals**
2. Signals are ranked by confidence
3. Click any signal to see full analysis
4. Filter by asset class (Crypto, Forex, Stocks)

### Paper Trading (Risk-Free Testing)

**What is Paper Trading?**
- Simulated trading without real money
- Perfect for learning
- Tracks performance metrics
- No financial risk

**Getting Started**
1. Navigate to **Paper Trading**
2. Click **"New Trade"**
3. Select trading pair (BTC/USD, EUR/USD, etc.)
4. Choose BUY or SELL
5. Set quantity
6. Click **Execute**

### Portfolio Tracking

**View Your Portfolio**
- Dashboard shows total value
- Tracks P&L (profit/loss)
- Shows allocation by asset
- Real-time updates

**Key Metrics Explained**
- **Total Return**: % gain/loss from initial capital
- **Win Rate**: % of profitable trades
- **Sharpe Ratio**: Risk-adjusted returns (higher = better)
- **Max Drawdown**: Largest peak-to-trough decline

### Exchange Integration

**Connect Your Exchange**
1. **Settings** → **Exchanges**
2. Select exchange (Binance/OKX/Bybit)
3. Generate API keys on exchange:
   - Enable "Enable Spot Trading"
   - Enable "Enable Margin Trading" (optional)
   - Disable "Enable Withdrawals"
   - Set IP whitelist
4. Paste API key & secret
5. Click **Connect**

## Risk Management

### Understanding Risk Metrics

**Sharpe Ratio**
- Measures risk-adjusted returns
- Higher = better risk management
- Formula: (Return - Risk-free rate) / Volatility
- Target: > 1.0

**Maximum Drawdown**
- Largest peak-to-trough decline
- Shows worst-case scenario
- Important for capital preservation
- Acceptable: -10% to -30%

**Win Rate**
- % of profitable trades
- 50% win rate is breakeven
- Needs good risk/reward ratio
- Target: > 55% with good R:R

### Risk Controls in AlphaForge

**Automatic Controls**
- Daily loss limits auto-close positions
- Position size limits prevent concentration
- Circuit breakers halt trading if thresholds hit
- Margin requirements automatically enforced

**Manual Controls**
- Set stop loss on each trade
- Use take profit to lock in gains
- Adjust position size for volatility
- Monitor drawdown in real-time

## Compliance

### KYC Requirements

**Why KYC?**
- Regulatory compliance
- Money laundering prevention
- Fraud prevention
- Risk assessment

**KYC Levels**
- **Level 1**: Basic (email + phone)
- **Level 2**: Verified (ID + Address)
- **Level 3**: Premium (Income proof)

### Account Security

**Best Practices**
1. Use strong, unique password
2. Enable 2FA (Google Authenticator)
3. Never share API keys
4. Rotate keys every 90 days
5. Use IP whitelist

### Trading Restrictions

- T-1 rule: Most trades settle next day
- Pattern day trading: Minimum $25k for frequent trading
- Margin requirements: 50-200% depending on asset
- Trading hours: Some pairs have restricted hours
